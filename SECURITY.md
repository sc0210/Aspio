# Security policy

Please report vulnerabilities privately through GitHub: **Security → Report a vulnerability**
on this repository. Do not open a public issue for a security problem.

Include what you found, how to reproduce it, and what an attacker could do with it. You should
hear back within a week.

Only the `main` branch is supported.

How the app handles auth, secrets and CI is described in [`docs/SECURITY.md`](docs/SECURITY.md).
