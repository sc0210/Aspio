# Architecture review, 2026-11-01

Scope: backend, frontend, the production stack (`docker-compose.pi.yml`, Caddy, `scripts/aspiro`) and the dev workflow. Each finding is ranked for security or performance, and carries the check that measures it before and after the fix.

How the scan ran. Four read-only scans (backend security, backend performance, frontend, deployment) read the code. The top claims of each were then re-read by hand, and every value in the **Before** column was captured on 2026-11-01 from the local stacks (`aspiro-*` dev, `aspiro-prodlocal-*` production build). A row marked *read* was confirmed by reading the code; *probed* means a command was run; *inferred* means neither.

Out of scope: the uncommitted edits in `loans/repositories.py`, `loans/service.py` and `transactions/services.py` (another session's work).
